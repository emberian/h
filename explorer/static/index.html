    Start here

    h is a small language model that lives in a library of scanned books and sits in a Discord room, answering when spoken to, briefly, in the words of what it has read. This explorer is a workbench for reading h closely rather than chatting with it: every sampled token is shaded by its probability, any answer can be traced back to the books, alternative rooms can be scored against each other, and the room's real decisions can be replayed. Pick a line for h below, then choose a way in.
